# Бот «Первый год»

Telegram-бот + мини-приложение на Cloudflare Workers (бесплатный план) и D1.
Семья = 1–4 ребёнка (двойня ведётся вместе) + 1–4 родителя. Отметки общие, каждая цветом того, кто отметил.

## Где что лежит

| Путь | Что |
|---|---|
| `public/data.js` | **Весь контент**: недели, задания, подсказки, вещи (`GEAR` по разделам `GCAT`, «Не покупать» `GEAR_SKIP`), сезонные уведомления `NOTICES`, рутина, флаги, первая помощь, календарь прививок (`VACCINES`, с источниками). Общий для бота, приложения и артефакта |
| `public/app.js`, `app.css`, `index.html` | Мини-приложение: Сегодня (полоса дней и календарь рутины) / Кормление / Советы / Рост / Вещи / Семья + поиск (первая помощь — через поиск и «Советы») |
| `public/anim.js` | Анимации-подсказки «как делать» (SVG); движение — в `app.css`, блок `.an-` |
| `public/search.js` | Поиск по всему контенту |
| `public/fonts/` | Golos Text TTF (OFL 1.1) — кириллица для PDF-сводки, которую собирает приложение (jsPDF с cdnjs) |
| `public/cards/` | Готовые PNG: `wNN.png` — карточки недель, `mNN.png` — поздравления с месяцами |
| `media/anim-*.mp4` | Видео анимаций для просмотра и отправки (`npm run video -- bike`) |
| `src/worker.js` | Вебхук бота, API приложения, утренняя рассылка (cron), экспорт/восстановление |
| `src/tg.js` | Telegram Bot API, отправка файлов (`sendDocument`), проверка initData |
| `src/cards.js` | Разметка PNG-карточек |
| `docs/motion-list.md` | Что ещё нарисовать из анимаций |

## Команды

```bash
npm run dev                 # локально, .dev.vars с DEV=1 (без Telegram)
npm run render              # перерисовать PNG карточек после правок data.js
npm run video -- bike       # MP4 анимации: bike | knees | hug
npm run build:artifact      # пересобрать артефакт ../first-year-plan.html
npm run deploy
```

Локально без Telegram: `http://localhost:8787/?dev_user=1&dev_name=Тест` — второй родитель `?dev_user=2`.

## Сценарии

- **Онбординг:** «малыш родился» (можно двойню) · «ждём малыша» (имя и ПДР можно пропустить) · «просто посмотреть» (демо, ничего не сохраняется).
- **Ждём:** экран с отсчётом до ПДР и счётчиком базового набора (вещи с `need:0`) → «Вещи» → «Весь список»; раз в неделю напоминание в бот; после ПДР — «Малыш уже родился?». Кнопка «Родился!» во вкладке «Семья».
- **Двойня:** одна неделя и одна карточка на двоих, у каждой строки рутины и заданий отметка на каждого ребёнка. Дети разного возраста — переключатель вверху.
- **Второй родитель:** «Семья» → «Отправить приглашение» → ссылка `t.me/<бот>?start=inv_…`.
- **Первая помощь:** отдельной кнопки SOS нет. Поиск (лупа в шапке) и «Советы» → «Первая помощь»; статья с номерами 103/112. `/sos` в боте открывает поиск по первой помощи (`?sos=1`).
- **Календарь рутины:** дни в полосе на «Сегодня» кликабельны (прошлые можно отмечать), месячный/годовой календарь с кольцами прогресса. `/api/state` отдаёт отметки рутины за 62 дня и счётчики `routineDays` за всё время, `/api/day?date=` — отметки старого дня.
- **Советы:** статьи собираются в `public/tips.js` из существующего контента; закладки — `b:<статья>:u<родитель>` в `checks`.
- **Каждое утро** (06:00 UTC): поздравление с месяцем → карточка новой недели → иначе рутина на сегодня. Одинаково всем родителям семьи. Плюс прививки: за 3 дня и в день (по плану или с записью; платные рекомендованные — только если записались).
- **Прививки:** при дате рождения создаётся план по календарю МОЗ (наказ №595 в ред. №396, с 01.01.2026) на каждого ребёнка, двойне — отдельно. Статус в одно касание: по плану → записались → сделано; дата и время записи, дата прививки, заметка (клиника, серия, реакция). Свои записи (Манту и т. п.) можно добавлять и удалять. Блок на «Сегодня» (просрочено — красным, ближайшие 14 дней — жёлтым), полный список — из «Сегодня», недели («Врач»), «Флагов» и «Семьи». Таблица `vaccines`.
- **Вещи:** «Пора заказать» — вещи с `need ≥ 4` за 3 недели до нужной недели (карточка недели, утренняя рассылка); «Весь список» — все разделы, отметки «есть» (`val 1`) и «не нужно» (`val 2`), блок «Не покупать».
- **Важное:** сезонные уведомления (`NOTICES`: отопление, жара, окна). Карточка на главной в своё окно; «Понятно, скрыть» — у каждого родителя своё (`n:<id>:<сезон>:u<id>` в `checks`), архив — «Семья» → «Прочитанные уведомления». Бот шлёт один раз за сезон на семью в первое утро push-окна (отметка `notice:<семья>:<id>:<сезон>` в `settings`).
- **Данные:** «Семья» → «Скачать копию данных» (или `/export`) — бот присылает JSON `{app:"first-year", version:1, …}`: дети, родители, все отметки, прививки. «PDF-сводка» — собирается в приложении и приходит в чат документом. «Восстановить из копии» — JSON сливается с текущими данными (отметки и прививки; ничего не удаляется, дети сопоставляются по дате и имени).

## Развёртывание (один раз)

```bash
npx wrangler login
npx wrangler d1 create rita              # database_id → wrangler.toml
npx wrangler d1 execute rita --remote --file=schema.sql   # и после обновлений: только CREATE … IF NOT EXISTS
npx wrangler secret put BOT_TOKEN        # от @BotFather
npx wrangler secret put WEBHOOK_SECRET   # длинная случайная строка
npx wrangler deploy                      # APP_URL в wrangler.toml = выданный адрес, затем deploy ещё раз
```

Потом открыть `https://<адрес>/setup?key=<WEBHOOK_SECRET>` — ставит вебхук, команды и кнопку меню (открыть ещё раз после обновления — добавятся новые команды).

Команды бота: `/sos`, `/today`, `/week`, `/card N`, `/flags`, `/vaccines` (просроченные и ближайшие прививки), `/export` (копия данных файлом).
Проверка рассылки без ожидания утра: `/run-daily?key=<WEBHOOK_SECRET>&family=1`.

## Продакшн: свой сервер через Coolify

На сервере воркер работает под Node (`server.mjs`): D1 → SQLite в томе (`/data/rita.db`), cron → таймер после 06:00 UTC, вебхук `/tg`.
Coolify-приложение типа dockerimage, образ `localhost:5000/rita-bot:latest`; создаётся один раз `deploy/coolify-create.sh`.

Файлы на сервере (в репозитории их нет):
- `/root/.rita_bot_token`, `/root/.rita_webhook_secret`, `/root/.coolify_token` — секреты;
- `/opt/rita-bot/.app_url` — адрес приложения, `/opt/rita-bot/.coolify_app` — uuid приложения в Coolify.

Обновить (с ноутбука, из `bot/`): скопировать с LF и запустить деплой на сервере —
```bash
S=$(mktemp -d) && cp -r Dockerfile .dockerignore server.mjs schema.sql package.json src public deploy $S/ \
 && find $S -type f \( -name '*.js' -o -name '*.mjs' -o -name '*.sh' -o -name '*.sql' -o -name '*.json' -o -name '*.html' -o -name '*.css' -o -name Dockerfile \) -exec sed -i 's/\r$//' {} + \
 && tar czf - -C $S . | ssh <сервер> 'tar xzf - -C /opt/rita-bot && sh /opt/rita-bot/deploy/deploy.sh'
```
`deploy.sh`: бэкап базы в `/opt/rita-bot/backups` (20 штук) → сборка → смоук-тест → push → redeploy → `/setup` (вебхук, команды, меню).
